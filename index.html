Chess Reels Publisher

A private tool that renders short cinematic chess videos and publishes them to our own YouTube, Instagram and Facebook accounts using the platforms' official APIs.

What it uses Google APIs for

It uses the YouTube Data API with the youtube.upload scope solely to upload videos we create to our own channel. It does not read, collect, or share any other user's data.
