Privacy Policy

Ant-Wars Publisher · last updated 21 September 2026

Ant-Wars Publisher ("the app") is a private tool operated by Karim. It generates ant colony simulation videos and publishes them to a YouTube channel that the operator owns and controls. The app has no other users.

What the app does

The app renders video files on the operator's own server and, on a schedule the operator sets, uploads them to the operator's YouTube channel through the official YouTube Data API v3.

Data the app accesses

  • An OAuth token for the operator's own YouTube account, used solely to upload videos the operator generated and to set their thumbnails. The token is stored as an environment variable on the operator's private server and is never shared or transmitted anywhere else.
  • Video files, titles, descriptions and thumbnails created by the app itself.
  • The video ids returned by YouTube, kept in a local file so a short clip can link back to the full match.

Data the app does not collect

The app does not collect, store, sell or share any personal data belonging to any other person. It does not read subscribers, comments, messages, watch history, analytics or audience data. It does not use Google user data for advertising, profiling or training models. Visitors to this website are not tracked; there are no cookies, no analytics and no third-party scripts.

Scopes requested

  • https://www.googleapis.com/auth/youtube.upload — upload the operator's videos.
  • https://www.googleapis.com/auth/youtube — set a custom thumbnail on those uploads.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Rendered videos are deleted from the server automatically after ten days. The OAuth token stays valid until the operator revokes it at myaccount.google.com/permissions, which immediately ends the app's access. Uploaded videos can be deleted by the operator in YouTube Studio at any time.

Third parties

The only third party involved is Google/YouTube, which receives the uploaded videos and their metadata. Nothing is shared with anyone else.
