Privacy Policy

Draksyn Reels Publisher · last updated 27 September 2026

Draksyn Reels Publisher ("the app") is a private tool operated by Karim. It generates music reels for the operator's own tracks (released as draksyn) and publishes them to a YouTube channel that the operator owns and controls. The app has no other users.

What the app does

The app renders video files on the operator's own server and, on a schedule the operator sets, uploads them to the operator's YouTube channel through the official YouTube Data API v3.

Data the app accesses

  • An OAuth token for the operator's own YouTube account, used solely to upload videos the app generated, set their thumbnails and read the status of those uploads. The token is stored in a file readable only by the service account on the operator's private server and is never shared or transmitted anywhere else.
  • Video files, titles, descriptions, tags and thumbnails created by the app itself.
  • The video ids, privacy status, processing state and public view / like / comment counts of the operator's own uploads, returned by YouTube. They are kept in a local log so the same video is never uploaded twice, and summarised in a status message sent to the operator's own private Discord channel.

Data the app does not collect

The app does not collect, store, sell or share any personal data belonging to any other person. It does not read subscribers, comments, messages, watch history, analytics or audience data. It does not use Google user data for advertising, profiling or training models. Visitors to this website are not tracked; there are no cookies, no analytics and no third-party scripts.

Scopes requested

  • https://www.googleapis.com/auth/youtube.upload — upload the operator's reels and set their thumbnails.
  • https://www.googleapis.com/auth/youtube.readonly — confirm the correct channel is linked and read the status and public counts of the operator's own uploads.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Retention and deletion

Rendered videos are deleted from the server automatically three days after they are uploaded; a small record of each upload (file name, video id, title, upload time) is kept. The OAuth token stays valid until the operator revokes it at myaccount.google.com/permissions, which immediately ends the app's access; the stored token and upload records are then deleted from the server. Uploaded videos can be deleted by the operator in YouTube Studio at any time.

Third parties

The only third party that receives data is Google/YouTube, which receives the uploaded videos and their metadata. Status summaries about the operator's own uploads go only to the operator's private Discord channel. Nothing is shared with anyone else.
